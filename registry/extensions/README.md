# Extensions

Reserved. Not open for submissions yet.

This directory exists so the registry is namespaced by kind from the start —
`registry/<kind>/<id>`, release tags `<kind>-<id>-v<version>`, and an
`index.json` keyed by kind. Adding a second kind later is then a matter of
opening this directory, not renaming paths and breaking every published URL.

If you have an idea for what an Amee extension should be able to do, open a
discussion on the [Amee docs](https://docs.amee.thiennguyen.dev).
